# Frequency Forge Android

## v1.1 stereo controls

Each of the 9 layers has independent LEFT and RIGHT channel controls for frequency, waveform, phase, and volume. Phase values are absolute per-channel oscillator offsets (0°, 45°, 90°, 180°). Old v1 presets are migrated by mapping the old shared waveform to both channels, left phase to 0°, and the old right-vs-left phase to the new right phase.
